00Project Positioning

What this is

hanglisimonwang is Simon Wang's private research workspace, built on the DocAI platform — a fullstack web app (Express + React + Postgres on Replit) for academic-paper publishing. It integrates with Google Workspace (Drive, Docs, Mail, Calendar, Sheets) and provides paper-publishing tooling: manuscript review, OpenReview integration, systematic reviews, reading-list tracing, lab-meeting minutes, scientific figures, posters, slides, and an AI chat aware of the active document context.

Who this page is for

Other AI agents (Cursor, Claude Code, Codex CLI, etc.) that Simon points at this workspace. Read this first, then ask Simon for a personal-access token to clone the private repo.

What is not here

Confidential research data, manuscript drafts, participant data, internal credentials, or anything covered by an NDA. This page lists only public, non-sensitive structural information.

01Access

The actual workspace is a private GitHub repository. To work on it you need an access token from Simon.

cd hanglisimonwang
cat replit.md          # canonical agent instructions

04Code-Reading Method

Recommended reading order when you first land in the repo:

  1. replit.md — canonical agent instructions, scope, conventions
  2. shared/schema.ts — data model (Drizzle + drizzle-zod)
  3. server/routes.ts + server/features/ — API surface and feature modules
  4. client/src/App.tsx — frontend routing (wouter)
  5. projects/linda-speaking-research/plan.md — current research project (collaboration with Prof. Li — read-only unless invited)

Key conventions

  • PostgreSQL snake_case columns ↔ TypeScript camelCase
  • Drizzle migrations are additive-only — never destructive
  • Routes stay thin; business logic lives in server/services/ and server/features/
  • System prompts are Markdown files in server/prompts/ and prompts/
  • All log.error() calls and audit events are persisted to the chat_logs table

05External Dependencies

  • Google Workspace — sole identity provider (Google OAuth) and primary document/data integration (Drive, Docs, Mail, Calendar, Sheets, Tasks)
  • LLM APIs — chat, content generation, tool execution (via Replit AI Integrations / OpenRouter)
  • OpenAlex — academic metadata lookup

Removed: Feishu, Tencent Docs, Shimo, WeChat, Aliyun SMS, Suno, Zoom, Three.js direction lab.
