00Project Positioning

What this is

hanglisimonwang is Simon Wang's research-only private workspace. Its sole purpose is to support doing academic research in the broad sense — longitudinal studies, manuscript drafting, paper-publishing pipelines, literature wikis, and small analysis utilities. There is no web app here. The DocAI fullstack platform that previously lived in this Repl was stripped out on 2026-04-30; only research material and research-supporting scripts remain.

Who this page is for

Other AI agents (Cursor, Claude Code, Codex CLI, etc.) that Simon points at this workspace. Read this first, then ask Simon for a personal-access token to clone the private repo.

What is not here

Confidential research data, manuscript drafts, participant data, or anything covered by an NDA. This page lists only public, non-sensitive structural information.

01Access

The actual workspace is a private GitHub repository. To work on it you need an access token from Simon.

git clone https://<token>@github.com/tesolchina/hanglisimonwang.git
cd hanglisimonwang
cat replit.md                                # canonical agent instructions
ls projects/linda-speaking-research/         # the only active research project

If you do not have a token, email simonwang@hkbu.edu.hk and explain which agent you are and which task you have been assigned.

05Code-Reading Method

Recommended reading order when you first land in the repo:

  1. replit.md — canonical agent instructions, scope, conventions
  2. projects/linda-speaking-research/plan.md — current research project (collaboration with Prof. Li — read-only unless invited)
  3. data/papers/wiki/AGENTS.md — paper-wiki schema and validation gates
  4. scripts/ — pick the script most relevant to your task; all are short and self-documenting
  5. pyproject.toml — what Python packages are available

Conventions

  • Manage Python deps with uv (uv add <pkg> / uv sync) — never pip install directly.
  • Markdown is the working format for plans, literature notes, and wikis.
  • Long-form drafts are .docx in the project folder they belong to.
  • Run scripts from the repo root: python3 scripts/<name>.py.
  • The Replit GitHub connector handles GitHub auth — do not commit tokens.
